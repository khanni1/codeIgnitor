If you already know some Django, then learning CodeIgniter becomes much easier because both follow MVC concepts.

Here’s the Django → CodeIgniter mapping first:

| Django                | CodeIgniter 4           |
| --------------------- | ----------------------- |
| urls.py             | app/Config/Routes.php |
| views.py            | app/Controllers/      |
| models.py           | app/Models/           |
| templates/          | app/Views/            |
| settings.py         | app/Config/ + .env  |
| manage.py runserver | php spark serve       |

# 3. URLs (like urls.py)

File:

text
app/Config/Routes.php


Example:

php
$routes->get('/', 'Home::index');
$routes->get('/about', 'Home::about');


Meaning:

* / → calls Home controller index() method
* /about → calls about() method

# 4. Views / Controllers (like views.py)

Create:

text
app/Controllers/Home.php


php
<?php

namespace App\Controllers;

class Home extends BaseController
{
    public function index()
    {
        return "Hello World";
    }

    public function about()
    {
        return "About Page";
    }
}

* localhost:8080/
* localhost:8080/about

# 6. Passing Data to Templates

Controller:

php
public function index()
{
    $data = [
        'name' => 'Khanjan',
        'city' => 'Ahmedabad'
    ];

    return view('home', $data);
}


View (home.php):

php
<h1><?= $name ?></h1>
<p><?= $city ?></p>


<?= ?> is short PHP echo syntax.

# 7. Models (like models.py)

Create:

text
app/Models/StudentModel.php


php
<?php

namespace App\Models;

use CodeIgniter\Model;

class StudentModel extends Model
{
    protected $table = 'students';

    protected $allowedFields = ['name', 'email'];
}


Use model in controller:

php
use App\Models\StudentModel;

public function students()
{
    $model = new StudentModel();

    $data['students'] = $model->findAll();

    return view('students', $data);
}

# 10. Forms

Route:

php
$routes->get('/contact', 'Home::contact');
$routes->post('/submit', 'Home::submit');


Controller:

php
public function contact()
{
    return view('contact');
}

public function submit()
{
    $name = $this->request->getPost('name');

    return $name;
}


View:

html
<form method="post" action="/submit">

<input type="text" name="name">

<button type="submit">Send</button>

</form>
